# TUM-EIKON Rechnerräume KDE Chinese Font Fix

Install Chinese fonts without sudo in TUM EIKON Rechnerräume.

为你的TUM机房电脑安装中文语言包——专门为慕尼黑工业大学主校区的EI专业的学生们准备的汉化包。

以下操作内容需要在命令行工具中打开，主校区机房电脑的命令行工具位置如下：
1.Meta键(也就是Win键)打开菜单栏 → Konsole(KDE的命令行工具)
或者
2.Ctrl + Alt + T 直接打开 Konsole。

然后就可以顺着接下来的流程一个一个把内容复制粘贴进去了。
(终端中复制粘贴要 +Shift ：Ctrl + Shift + C/ Ctrl + Shift + V )

## Install

```bash
git clone https://github.com/andycr0w/ubuntu-chinese-font-fix.git


cd ubuntu-chinese-font-fix


chmod +x install.sh


./install.sh
```

## Uninstall

```bash
chmod +x uninstall.sh


./uninstall.sh
```
